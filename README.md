# Список задач

Приложение для ведения задач с сохранением данных в браузере.

## Возможности

- Добавление задач с проверкой текста и длины.
- Отметка выполненных задач и их удаление.
- Автоматическое сохранение в `localStorage` и восстановление после обновления страницы.
- Адаптивный интерфейс, доступный с клавиатуры.

## Технологии

React, TypeScript, Vite, CSS, Vitest и React Testing Library.

## Установка и запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

## Проверки и тесты

```bash
npm run typecheck
npm run lint
npm run format:check
npm run test:run
npm run build
```
